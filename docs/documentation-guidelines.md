# VitePress 文档内容规范

适用于 `website/` 下的使用指南、组件页面和示例。本文随仓库维护；设计、实现与验收资料保存在 `docs/.codex/`。

## 页面顺序

参考 [Element Plus 按钮文档](https://element-plus.org/zh-CN/component/button)的阅读顺序，组件页统一采用：

1. **组件概要**：标题后一至两句，说明用途和主要能力。
2. **用法说明**：从基础用法开始，按展示模式或使用目标分节；每节先用一至两句说明关键属性及效果。
3. **必要提示**：仅在存在易误用的前提、责任或限制时添加，放在对应演示前。
4. **交互展示**：直接体验本节能力。
5. **折叠代码**：紧随演示，默认收起，按需查看。
6. **API**：集中在页面末尾，按属性、事件、插槽、实例方法、类型和样式变量组织；没有的项目省略。

第 2～5 项按用法重复，不建立“组件概要”“展示模式说明”等空泛标题。标题直接使用“图标按钮”“跨页勾选”等用法名称。纯说明指南按任务组织，不强套组件模板。

## 文案取舍

- 一节通常只写一段说明。超过三句时，检查是否应删减、拆成另一种用法，或移入 API。复杂使用契约可适当展开。
- 说明只回答“设置什么、有什么效果”；演示已经直观表达的颜色、位置、按钮文字和操作步骤不再逐项复述。
- 提示使用 `::: tip` 或 `::: warning`，一般一至两句；没有必要提示就省略，避免每节堆叠提示框。
- 正文讲用法，API 查参数。同一默认值、参数解释和限制只完整说明一次，其他位置按需链接。
- 保留会影响接入或结果的契约：受控状态、数据赋值时机、事件参数、是否自动关闭、请求失败处理及公开样式定制方式。
- 删除内部调用链、转发过程、私有组件与 DOM、布局算法、精确动画时间、适配原理、改造理由、修复历史和验收说明；时间值本身是公开可配置能力或业务契约时除外。
- 不罗列组件未提供的能力，不反复提醒使用公开入口，不用“统一语义”“沿用协议”等抽象表述代替具体用法。

| 冗长或偏实现的说明                                       | 推荐写法                                             |
| -------------------------------------------------------- | ---------------------------------------------------- |
| 组件读取插件注入的状态，不自行创建或持久化主题           | 使用前链接主题初始化章节                             |
| 通过尺寸观察和网格计算，在多档列数之间重新排列           | 卡片随容器宽度调整列数                               |
| loading 替换内部图标并设置状态，不改变原形态             | 设置 `loading` 显示加载状态并禁用点击                |
| 初始化、回填和内部同步不会触发业务变更，组件不修改行对象 | 开关由调用方在保存成功后回写；仅用户操作触发变更事件 |

## 示例和代码

- 每个演示围绕一个目标，优先使用最小配置；综合场景作为补充，不代替基础用法。
- 每个演示后提供对应的折叠代码。使用 VitePress `::: details 查看代码`；局部代码标为“查看配置片段”，并简要说明省略的业务依赖。
- 完整代码包含必要导入、状态和处理函数，使用 `@yyitian/web-toolkit` 公开入口；Vue API 显式导入。站点预览可引用当前源码，但展示给读者的代码不得依赖私有路径。
- 代码与演示的关键属性、初始状态和交互结果一致。API 类型签名和短配置表可直接展示，不强制折叠。
- 按钮优先 `SuperButton`，多项配置与校验优先 `SuperForm`，弹窗和提示复用对应组件，确认与日期处理使用公开工具方法。单项控件可用已有 Element Plus 控件。
- 原生元素用于语义内容或专门演示通用参考元素等能力，不作为辅助按钮的默认实现。
- 模拟请求、上传和保存明确标注；操作可重复、可取消或恢复。动态图标共用一个 `active`，开关最左，点击任意图标统一切换。

## 演示分区与主题

| 区域           | 内容                                   |
| -------------- | -------------------------------------- |
| 控制区（可选） | 尺寸、模式、数据量、禁用等辅助条件     |
| 展示区         | 目标组件及其搜索、分页、提交等正常操作 |
| 结果区（可选） | 有助理解事件或提交结果的反馈           |

- 通过间距、分隔线或简短标签区分区域；简单演示不增加空控制区。状态已由控件表达时不重复输出文字，不展示调试信息。
- 同级展示区使用统一主题背景、边框和文字；复用全站主题入口与状态，展开的弹窗、下拉和 Popover 同步响应四种主题。
- 组件主题效果在各自使用页面的正常示例中查看，直接响应文档站主题，不额外建立主题演示。没有独立组件的公共样式集中在主题指南的一个章节展示。
- 外壳不叠加独立渐变、实色底板或装饰背景。保留业务状态色、示例图片和反色文字所需背景；颜色定制场景明确标注对照条件，默认跟随主题。

## 集中说明与组合去重

- 安装、样式引入、主题初始化集中在指南维护。组件页仅在有特殊前提时链接具体章节，不逐页重复接入说明。
- 组合组件只讲最小配置和新增差异，通用教程链接原组件。表单弹窗链接表单与弹窗；卡片视图链接表格查询、搜索和分页；标签与状态链接各自页面。
- 没有特殊使用约定的内置字段收纳到综合示例，不按字段类型重复建立教程。必要的默认值保留在 API。
- API 只列自身公开配置和必要复用关系，不复制子组件完整 API。保留仍有价值的章节锚点，移动内容后检查全部引用。
