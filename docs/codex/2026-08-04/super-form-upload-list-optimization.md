# SuperFormUpload 文件与图片列表优化

## 目标

在不改变 `v-model`、上传适配器、数量限制和 `action` 事件协议的前提下，压缩文件列表视觉高度，并将图片删除操作改为网格内常驻角标。

## 组件复用

- 上传和删除操作统一使用项目内 `SuperButton`，不直接创建原生按钮。
- 文件、加号和删除图标统一通过 `SuperIcon` 渲染 Lucide 图标，保持 `16px`、`32px` 和 `14px` 的既定尺寸。
- 局部样式适配 `SuperButton` 的 Element Plus 根节点与图标包装层，不改变按钮的禁用、无障碍名称和事件语义。

## 文件列表

- 文件模式和文件列表默认占满可用宽度。
- 文件行取消边框和上下内边距，高度与行高统一为 `24px`。
- 文件名前固定显示文件图标，长文件名继续单行省略。
- hover 时使用浅色背景，文件图标和文件名切换为 primary 主题色。
- 删除按钮保持在每行最右侧，保留禁用状态与无障碍名称。

## 图片列表

- 删除按钮从 hover 浮层移入每张图片的右上角并始终显示。
- 删除图标使用 danger 主题色描边，背景为右上角半透明白色三角形。
- 图片 hover 时仅放大图片内容，缩放效果不越出 `96px` 网格，删除角标、边框和 `+N` 遮罩不随之缩放。
- 删除按钮阻止点击冒泡，避免删除操作同时打开图片预览。

## 兼容性

- 图片九宫格、完整图片预览、上传 Skeleton 和 `+N` 计算保持原有规则，上传占位与已有图片合计不超过八个内容格，加上上传入口最多九格。
- local/remote 上传、预览 URL 释放、limit 校验和删除事件语义保持不变。

## 双阶段占位

- remote 上传等待阶段使用带 `animated` 的 `ElSkeleton`：文件占位为 `24px` 高、`100%` 宽，图片占位为 `96px` 方格。
- 每个远程图片进入 `ElImage` 后，在 URL 加载完成前通过 `placeholder` 插槽显示同尺寸动画 Skeleton；加载完成后原位替换为图片，不产生布局跳变。
- 上传阶段占位仍受九宫格最大可见数量限制；URL 加载阶段占位属于对应的已有图片格，不参与 `+N` 和预览索引计算。
